# Consensus

The signing matrix: which validators signed the most recent blocks.

## Sub-features

- One heading, `XRPL EVM Sidechain consensus signing matrix`, and the
  matrix itself.

## How to get to it (user POV)

Click **Consensus** in the sidebar.

## Driving it with drive.mjs

`consensus`: load `/consensus` and wait for the heading.

## Gotchas

- The journey proves the page renders, not that the matrix is right. A
  change to the matrix needs its screenshot read against the validator
  list.
